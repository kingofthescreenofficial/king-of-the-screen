# King of the Screen. Privacy Notice

**Effective date:** 5 September 2026

**Status:** Accurate for the current pre-launch build. Review before any paid launch or new third-party integration.

## 1. Scope

This notice covers `kingofthescreen.fun` during pre-launch. The site does not accept payments, wallet connections, content uploads, user accounts, NFT minting, or KOTS claims.

## 2. Data handled by the current site

The application stores a page path and a timestamp when the page-view telemetry endpoint receives a valid page-view event. The application stores a short random session identifier and last-seen time for active-session counting. Active-session entries expire after 30 seconds.

The server, CDN, hosting provider, and security systems can process standard request information such as IP address, user agent, request time, URL, response code, and security logs. Those records are controlled by the relevant infrastructure configuration.

The administrative area uses a strictly necessary, secure, HTTP-only session cookie after an administrator signs in. It is not used for advertising.

The current pre-launch build does not ask for a name, email address, wallet address, payment information, uploaded media, private key, seed phrase, identity document, or marketing profile.

## 3. Purpose and legal basis

The project uses application telemetry to understand basic site use, operate the service, detect abuse, secure the administrative area, and investigate incidents. It does not sell personal data or build advertising audiences.

## 4. Sharing

Data is available to hosting, security, and infrastructure providers that process it to run the site. Data can be disclosed where law requires it, to protect users or systems, or to respond to a valid legal process. The project does not sell page-view telemetry.

## 5. Retention

Application page-view telemetry remains in the application database until the project deletes it or replaces the pre-launch build. Active-session records are deleted after 30 seconds of inactivity. Hosting and CDN logs follow the retention settings of those providers.

Before a paid launch, the project must publish fixed retention periods, a working privacy contact, the actual list of vendors, applicable rights procedures, and cross-border transfer information.

## 6. Choices and security

Visitors can limit browser storage through browser settings. The pre-launch site has no visitor account and no user dashboard. Do not submit personal data, private keys, seed phrases, or payment details through the site.

## 7. Future changes

Wallet connection, payments, uploads, content moderation, NFTs, or KOTS would materially change this notice. Those features stay disabled until a revised notice is published and the technical controls are reviewed.
