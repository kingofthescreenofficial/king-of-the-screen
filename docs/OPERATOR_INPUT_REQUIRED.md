# Operator Input Required

Эти данные не нужны для текущего pre-launch сайта. Они нужны до публикации финальных Terms, включения оплат или создания KOTS v1.2 mint.

## 1. Публичная анонимность и право

1. Pre-launch сайт использует публичное имя проекта и не публикует личные данные создателя.
2. Публичная анонимность не освобождает оператора от требований закона, ответов на законные запросы или ответственности за фактические действия.
3. До первого платного запуска нужен правдивый contracting operator, адрес для legal notices, рабочий contact email и применимое право. Нельзя заменять эти данные вымышленным именем, фиктивным адресом или неработающим email.
4. Пока этих данных нет, публичный сайт остаётся только pre-launch и не принимает деньги.

## 2. Запуск аукциона

1. Список доступных стран и запрещённых стран.
2. Политика возврата, включая удаление контента после оплаты.
3. Максимальная длительность показа и условия досрочного takedown.
4. Кто принимает финальное решение по модерации и апелляциям.

## 3. KOTS v1.2 custody

1. Три публичных адреса будущего 2-of-3 multisig.
2. Отдельные адреса для Crown Rewards, Community Utility, Product Treasury и Team Vesting.
3. Подтверждение, что новый mint создаётся только после письменного заключения юриста США.
4. Подтверждение, что старый Pump.fun mint не будет рекламироваться как KOTS v1.2.

## 4. Безопасность

1. Отозвать раскрытый Helius API key и выпустить новый ключ.
2. Передать новый RPC URL только через `.env.local` на VPS. Не отправлять ключ в чат и не добавлять его в Git.
3. Подтвердить, что доступ к VPS panel и root credentials был обновлён после раскрытия в переписке.

## 5. GitHub

Production уже использует ветку `codex/production-hardening`. Нужна команда оператора перед переносом проверенных commit в `main`.
