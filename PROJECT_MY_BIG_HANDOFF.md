# 🚀 MASTER HANDOFF BLUEPRINT: Project "My Big" (Size Matters)

## 1. Суть нового проекта
**My Big (рабочее название)** — это вирусный Web3 degen-проект на Solana. 
Вместо выкупа рекламного места ("Король Экрана"), пользователи соревнуются в длине (фаллометрия). 
- **Механика:** Юзер платит SOL, чтобы сгенерировать или увеличить свой "размер" (Size).
- **Визуал:** Абстрактный/Юмористический (линейка, ракета, баклажан), чтобы избежать банов за жесткий NSFW, но сохранить суть.
- **NFT:** Фоновый воркер динамически генерирует SVG/картинку, где крупно написан финальный размер юзера, и чеканит (mint) её на кошелек.
- **Токеномика:** За каждый потраченный $1 юзер майнит токены проекта (например, $INCH или $SIZE).

---

## 2. Архитектура (Переиспользуем от "Короля")
Новый проект строится на 80% из кодовой базы `king-of-the-screen`. 
**Что нужно скопировать при старте:**
1. **Фронтенд:** Next.js 15, TailwindCSS, `WalletContextProvider.tsx` (со всеми провайдерами).
2. **Бэкенд:** Серверная стейт-машина (`lib/state.ts`), которая сбрасывает данные в `state.json`.
3. **API:** Обработчик транзакций (`api/takeover/route.ts`), который валидирует подписи Solana и пишет задачи в очередь.
4. **Фоновый воркер (Sentinel):** `airdrop_sentinel.js` (через PM2), читающий очередь `jsonl`, отправляющий токены и минтит NFT через Metaplex.

## 3. 🔴 КРИТИЧЕСКИЕ ОШИБКИ И ОПЫТ (НЕ ПОВТОРЯТЬ!)

### A. Баги мобильных кошельков (Phantom Android/iOS)
- **Проблема загрузки файлов:** В мобильном Phantom на Android открытие галереи (через `<input type="file">`) сворачивает кошелек. При возврате срабатывает биометрия, и ОС убивает контекст браузера — картинка не загружается.
- **Решение для нового проекта:** ИДЕАЛЬНО. В новом проекте юзеру **вообще не нужно грузить картинку**. Он только выбирает размер ползунком. Мобильная конверсия будет 100%.

### B. Инфраструктура Solana (RPC)
- `api.mainnet-beta.solana.com` — жесткие лимиты, отдает `failed to get recent blockhash` на мобилках.
- `rpc.ankr.com` — требует платный API ключ, иначе ошибка `403`.
- **РЕШЕНИЕ:** Использовать ТОЛЬКО `https://solana-rpc.publicnode.com` как в UI, так и на сервере. Работает железобетонно.

### C. API курсов валют (CoinGecko)
- Бесплатный CoinGecko блокируется адблокерами внутри браузера Phantom.
- **РЕШЕНИЕ:** Обязательно оборачивать fetch(SOL_PRICE) в `try/catch` с хардкод-фоллбэком (например, $150 за SOL).

### D. Деплой на слабом сервере (VPS Namecheap)
- Если запускать `npm run build` прямо в SSH, процесс убивается из-за нехватки RAM/CPU, а SSH отваливается.
- **РЕШЕНИЕ:** Все билды запускать только так: 
  `nohup bash -c 'npm run build && pm2 restart <process_name>' > build.log 2>&1 &`

## 4. ⚖️ Юридическая Броня (Копируем 1 в 1)
У нас идеальный юридический сетап. Новый ИИ должен внедрить его с первого дня:
1. **Click-Wrap:** Окно оплаты ДОЛЖНО иметь обязательный чекбокс *"I am 18+, I agree to TOS"*. Без галочки кнопка PAY не работает.
2. **Возраст:** COPPA compliance (строго 18+).
3. **Force Majeure:** Защита от исков, если блокчейн Solana ляжет или транзакция зависнет.
4. **OFAC Sanctions:** Заглушка от стран под санкциями США.
5. **No Gambling:** Пользователь покупает цифровой арт (NFT) и получает бесплатные токены. Никаких лотерей и обещаний профита.

## 5. 🛠 Что Новому ИИ нужно написать с нуля
1. **Динамические NFT:** Бот `sentinel` больше не грузит картинку от юзера. Он должен иметь функцию, которая принимает цифру (например, 25), генерирует SVG-картинку с красивой графикой размера, конвертирует в PNG и грузит в Arweave.
2. **Разделение кошельков:** Сгенерировать новый `hot_wallet_size.json` и новый адрес Казны (Treasury), чтобы бухгалтерия двух проектов не пересекалась на сервере.
3. **Механика Гачи/Апгрейдов:** Написать новую математику кривой в `state.ts`. Например: $1 дает рандомный стартовый размер. Каждые следующие $X добавляют +1 см.
4. **UI:** Заменить картинку-заглушку "Короля" на интерактивный спидометр, линейку или прогресс-бар.

**Инструкция для ИИ:** Когда пользователь скажет начать, создай директорию (например, `/var/www/my-big-size`), склонируй туда полезный код из папки Короля, и приступай к рефакторингу UI и логики.
