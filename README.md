# 👑 KING OF THE SCREEN

> Pre-launch status. Payments, NFT minting, KOTS claims, market operations, and the old Pump.fun token are disabled. Current product rules: `docs/KOTS_TOKENOMICS_V12.md` and `docs/LEGAL_LAUNCH_CHECKLIST.md`.

> **Один экран. Один король. Властвуй, пока тебя не свергнут.**

«King of the Screen» — автономная платформа реального времени, где любой пользователь планеты может захватить главный экран с сообщением, ссылкой и визуалом.

---

## ⚡ Главные особенности:

1. **Правило бесконечного правления**:
   * Никакого таймера на 60 секунд.
   * Король удерживает экран **до тех пор, пока следующий участник не перебьет ставку** ($1 -> $2 -> $5 -> $10... +10%).
   * Живой таймер правления (`Reign: 02:45:12`) фиксирует статус каждого правителя.

2. **Криптовалютный сбор без блокировок**:
   * Прямой прием на некастодиальные кошельки **Solana (SOL)**, **Base / EVM**, **USDT**.
   * Мгновенный **1-Click Demo режим** для тестирования и вирусных демонстраций.
   * Публичный прогресс-бар движения к цели **$1,000,000**.

3. **Graveyard of Kings & Hall of Fame**:
   * История всех свергнутых монархов, их потраченные суммы и длительность правления.
   * Фильтры по времени правления («Самый стойкий король») и по суммам («Топ-донатер»).

4. **Аудио-движок и AI-голос (TTS)**:
   * Синтезатор звуков сирены, кассы и фанфар через Web Audio API.
   * Голосовое объявление нового короля через браузерный SpeechSynthesis.

5. **Пакет автономных Hype-ботов (`bots/`)**:
   * `simulate_traffic.py`: Локальный симулятор битвы мемкоинов за трон.
   * `twitter_hype_bot.py`: Авто-публикация информации о новых ставках в X (Twitter).
   * `streamer_24_7.py`: Скрипт 24/7 стриминга экрана на Twitch/Kick/YouTube через FFmpeg.
   * `viral_content_pack.py`: Готовые сценарии для TikTok/Reels и посты для Reddit.

## 🚀 Быстрый запуск (Development):

```bash
# 1. Перейдите в папку web
cd VIRAL_SITE/web

# 2. Установите зависимости
npm install

# 3. Запустите сайт
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

---

## 🧪 Тестирование симулятора баталий:

В соседнем терминале запустите:
```bash
python3 VIRAL_SITE/bots/simulate_traffic.py 5
```
Вы увидите, как боты мгновенно начинают войну за трон, на сайте заиграют звуки сирен и сменится текущий правитель!
